# AI Agent Instructions for Common Utility Library (common_lib)

本プロジェクトにおける大賢者の開発指示書です。
最優先ルール（コミット禁止・テーブル整列等）は [[GEMINI.md]] を参照してください。

## 🎯 開発・品質ルール

- **技術解説方針（他言語経験への配慮）**:
  - ユーザーは他言語経験者ですがRust固有用語（所有権、ライフタイム、トレイト、マクロ等）には不慣れなため、直感的な一般的概念に置き換えるか分かりやすい補足を添えて報告してください。
- **事前検証とドキュメント同期**:
  - 開発およびドキュメント更新の際は、必ず [`docs/ja/INSTRUCTIONS.md`](../docs/ja/INSTRUCTIONS.md) に記載されている「対象ドキュメントと更新条件」および「品質管理・検証プロセス」に厳格に従って検証・同期を行うこと。
- **コード規模とリファクタリング**:
  - 1つのソースコードファイル（`.rs`）が 1,000 行を超えた場合は、保守性や可読性の低下を防ぐため、機能やサブモジュールごとにファイルを分割・リファクタリングすることを推奨します。
